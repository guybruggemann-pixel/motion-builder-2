# Motion Builder 2.0 — plan (summary)

Full, current plan with diagrams: https://claude.ai/artifact/DnRUjhGEjxW51N8FoYFBbv

## Flow
1. Drop in a design (Figma, SVG/PDF, image) → editable layer nodes with roles.
2. AI proposes three choreographies (smooth, punchy, playful) as scene doc JSON.
3. Refine with keyframes in the timeline or inside nested networks.
4. Export: After Effects (native layers), MP4 / ProRes with alpha, batch from .srt or CSV.

- [ ] 3D — scene layer, cloners and fields, Cinema 4D style (decided 2026-11-12, references in `docs/references/`). A **3D scene** layer is a subnet of 3D nodes that renders into the comp as one layer, so 2D type can sit above or below it. The core evaluates it (what is cloned where, which colour, every transform at time t; pure and seeded); three.js only draws it, the same code in preview and final render, frame-stepped. Gate per step below; preview and render match within tolerance (frame-diff tests).

Step 2 done: glyph outlines from the bundled variable fonts (`render/outlines.ts`, WOFF2 → TTF with wawoff2, weight + kerning with fontkit), widths identical to the canvas. Step 3 done: the three.js pass (`render/three/pass.ts`) draws the scene into an offscreen WebGL canvas that the 2D renderer composites as the layer: extruded text and shapes with inside bevels, physical materials with seeded grain, studio environments, directional / point / spot lights with soft shadows, AE-style camera; ~8 ms a frame at viewer size. Not yet: ambient occlusion (3D-d). Step 4 done: ProRes / MP4 and batch renders load the pass first (never the placeholder); a subnet rendered on its own keeps alpha; AE export turns each 3D layer into a footage layer and renders its ProRes 4444 pass into the folder with the .jsx (mock-AE tested, not yet run in real AE); `render/frameDiff.ts` with a first browser check on the 3D title: same frame twice identical, half-size preview vs full render mean diff 0.45/255. Step 5 done: materials UI. 12 starter materials (`core/scene/materials.ts`) and the open scene's own Material nodes in Library › Materials (click or drag onto an object; a material only one object uses is updated in place, a shared one stays shared and the object gets a new node); material inspector with kind buttons (a kind brings its defaults) and "Used by"; Look shows the wired material; the network has a material input on 3D objects. Look still to tune in 3D-d: metals need a brighter environment, glass doesn't refract the layers behind it yet, ambient occlusion): Scene3D subnet, Text 3D (extrude depth + bevel from the real font outlines, opentype.js), Extrude Shape, Camera (position, target, lens, keyed), studio light / environment (soft, hard, overcast), physical materials as nodes wired into a layer's `material` input (solid, plastic, plaster, glass, metal, iridescent, emissive; three.js `MeshPhysicalMaterial` params; brand kit `brand.materials` for reuse). Shadows and ambient occlusion. Flat layers with a non-solid material render through the same pass. AE: the 3D layer exports as a ProRes 4444 pass with alpha in its own precomp; 2D stays native. Gate: a rotating extruded title with soft shadows, preview = render.
