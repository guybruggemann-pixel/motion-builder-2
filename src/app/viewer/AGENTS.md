# src/app/viewer rules

- 3D in the viewer: clicks pick the 3D object under the pointer (`pick3D`, a raycast in the pass); empty 3D space falls through to what's below. Dragging a selected 3D object, or a selected 3D scene layer (its first object), turns it (`viewer/turn3d.ts`: left/right = Y, up/down = X, 0.4°/px, Shift = one axis) through `setValue`, one undo step per drag. A selected object inside a 3D scene is outlined with its projected box (`box3D`). The pass lives in one shared object on `globalThis` so every module copy uses it.
- Viewer tools (`uiStore.tool`, E / R): Move drags the selection (2D layers in comp px; 3D objects parallel to the screen via `planeDelta3D`), Turn turns 3D objects. The gizmo (`viewer/Gizmo.tsx`) puts X / Y (/ Z) handles on the selection's origin: arrows move along an axis, rings turn around it (`viewer/manipulate.ts`, tested). Axis colours are tokens `--axis-x/y/z`. Shift+click selects the part under the pointer: a precomp opens with the inner layer selected, a 3D scene with the object. The bottom card opens on the Network tab.
- Fields in the viewer (`viewer/FieldOverlay.tsx`): a selected Spherical or Linear field is drawn volt over ink (projected through the scene camera in 3D, network px in 2D). 2D cloners and effectors live in `evaluate.ts` (`evalNode` cases): copies are parts with offsets in `PartAnim`, and an effector colour sets `anim.fill`.
- Viewer picking picks the whole thing: a 3D scene layer (Move drags it in the comp; Turn turns its first object) and, inside a scene, a cloned object's Cloner (`Object3D.cloner`); Shift+click reaches the part.
